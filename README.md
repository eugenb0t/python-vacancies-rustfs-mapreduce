# Python-вакансии: RustFS, MapReduce и DuckDB

## Данные и правило выборки

В файле `/media/eugene/Data1/vacancies_2024.csv` содержится снимок вакансий 2024 года (CSV, UTF-8). Исходный CSV остаётся неизменным; в RustFS хранится его потоковая gzip-копия `s3://hh-lake/vacancies_2024.csv.gz`.

Вариант сегмента: **Python**. Вакансия включается, если `name` содержит подстроку `python` без учёта регистра **или** среди разделённых `;` значений `key_skills` присутствует отдельный токен `python` без учёта регистра. `description` не участвует. Навыки приводятся к нижнему регистру, дубликаты внутри вакансии удаляются; пары и тройки считаются как неупорядоченные комбинации навыков. Каждая строка CSV считается отдельной вакансией.

## Запуск

Окружение: Python 3, Docker Compose, `boto3`, `duckdb`. Скопируйте `.env.example` в `.env`, задайте собственные S3 ключи и абсолютный `RUSTFS_DISK_ROOT`, создайте там `disk0`…`disk7` и назначьте их владельцем UID/GID `10001` перед запуском контейнера. Не публикуйте `.env`. Для загрузки исходника предусмотрен `upload_dataset.py` (при необходимости задайте `RUSTFS_DATASET`).

```bash
cp .env.example .env  # затем задайте локальные ключи и каталог хранения
set -a; source .env; set +a
mkdir -p "$RUSTFS_DISK_ROOT"/disk{0..7}
docker run --rm --user 0:0 -v "$RUSTFS_DISK_ROOT:/mnt" alpine sh -c 'chown -R 10001:10001 /mnt/disk0 /mnt/disk1 /mnt/disk2 /mnt/disk3 /mnt/disk4 /mnt/disk5 /mnt/disk6 /mnt/disk7'
docker compose up -d
python -m pip install boto3 duckdb
python upload_dataset.py
python pipeline.py fail-test
python pipeline.py profile       # три полных прохода: 1k / 10k / 100k строк на блок
python pipeline.py duckdb        # независимый SQL-расчёт прямо по S3 gzip
python pipeline.py audit         # точное сравнение счётчиков
```

MapReduce читает S3-объект потоково через gzip и CSV, отображает блоки в локальные счётчики и объединяет их редьюсером. Профиль запускает три независимых полных прохода с блоками 1 000, 10 000 и 100 000 строк; для каждого сохраняются счётчики, распределение числа навыков на вакансию, вклад в C(k,2)/C(k,3), время, пиковая RSS и региональные агрегаты. JSON каждого прохода лежит локально и в `hh-lake/results/`. DuckDB одним проходом читает тот же S3 gzip через расширение `httpfs`, после чего вычисляет навыки, комбинации, зарплаты и регионы независимым SQL. Аудит сравнивает число вакансий, гистограмму и комбинации всех трёх уровней, вклад сочетаний и итог по трём регионам.

## Метрики и ограничения

Зарплаты считаются только для `currency=RUR`: если заданы обе границы, используется их середина; если одна — единственная граница. Для сопоставления пары/тройки с базовым одиночным навыком используется медиана наиболее часто встречающегося в сегменте компонента; комбинации с менее чем 30 вакансиями или 20 зарплатными наблюдениями исключаются. Показаны и максимальные повышения, и снижения медианы. Медиана описывает только объявления с указанной зарплатой и не является оценкой оффера. Три региона выбираются по числу вакансий сегмента; для каждого приводятся медиана зарплаты, покрытие и топ навыков/пар/троек. RustFS запущен на восьми каталогах хранения одного физического NVMe-диска: это учебная конфигурация с erasure coding, но не защита от потери физического носителя.

Подробные JSON с комбинациями остаются в RustFS; в GitHub публикуются код, методика, компактные агрегаты, PDF и скриншоты консоли, без исходного 25-ГБ CSV и ключей доступа.
